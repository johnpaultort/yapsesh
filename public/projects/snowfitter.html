Snowfitter

Ski & Snowboard Recommendation Platform

Python JavaScript HTML CSS
GitHub Live Demo

Overview

Snowfitter is created to save hard times. I came up with the idea since sometimes at Sports Basement South Bay we cannot attend all the customers. This creation allows customers to scan a QR Code to allow them to match their gear. Jae and JP have ridden most of the gear on the salesfloor to know what to feel with each one and can tell people if they should be on it or not. We also have done mistakes before taking trained professional advice.

Features

Ski Finder

Recommend skis based on ability, terrain, and snow conditions.

Boot Fitting

Returns boots to the customer according to their measurements. This requires last, mondo point, and instep.

DIN Calculator

Calculate recommended DIN settings using skier information.

Comparison Tool

Coming soon: Compare multiple skis side by side.
